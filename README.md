# ATM Management System 🏦

A Python-based ATM Management System with a modern Tkinter GUI, MySQL database integration, and voice-enabled assistance using pyttsx3.

---

## 🚀 Features

### 👤 User Features
- Secure Login System
- Balance Inquiry
- Deposit Money
- Withdraw Money
- Quick Cash
- Fund Transfer
- Change PIN
- Mini Statement
- Download Transaction History
- Voice Assistance

### 🛠️ Admin Features
- Admin Dashboard
- View All Accounts
- View Total Bank Balance
- Transaction History Access

### 🎨 GUI Features
- Modern Tkinter Interface
- Dark Theme UI
- Responsive Dashboard
- Optional Logo Support

---

## 🧰 Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python
- pyttsx3
